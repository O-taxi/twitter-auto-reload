# twitter-auto-reload

X のホームタイムラインにある更新ボタンを一定間隔で押す Chromium 拡張機能です。広告の非表示も個別に開始・停止できます。

## インストール

1. このリポジトリを取得します。
2. Edge の `edge://extensions` または Chrome の `chrome://extensions` で開発者モードを有効にします。
3. 「展開して読み込み」から、このリポジトリのフォルダを選択します。
4. X のホームを開き、拡張機能のポップアップから自動更新または広告の非表示を開始します。

ポップアップを閉じても設定と稼働状態は保存されます。自動更新は最初に見つかった X のホームタブに適用されます。広告の非表示は開いている X のタブすべてに適用されます。

## キーボードショートカット

- `Alt+Shift+R`: 自動更新の開始／停止を切り替えます。
- `Alt+Shift+P`: 広告の定期削除の開始／停止を切り替えます。
- `Alt+Shift+B`: 両方を同時に切り替えます。両方実行中なら両方停止し、それ以外なら両方開始します。

ショートカットはブラウザにフォーカスがあるときに動作します。割り当てが競合する場合は、Chrome の `chrome://extensions/shortcuts` または Edge の `edge://extensions/shortcuts` で変更できます。

## セレクターの編集

X の画面変更で更新ボタンや広告の検出が動かなくなった場合、`src/selectors.js` を編集してください。`timelineUpdateButton` は更新ボタン、`tweet` は投稿要素、`promotionLabels` は広告を判定する文字列です。編集後は拡張機能の管理画面で「更新」を押します。

自動更新の間隔は30秒以上で、各回に±20%の揺らぎを加えます。ただしブラウザのアラーム下限である30秒より短くはしません。広告の非表示は1分ごとに実行します。

## ファイル構成

- `manifest.json`: 拡張機能の設定
- `src/background.js`: アラームと各機能の処理
- `src/selectors.js`: X の画面要素を探す設定
- `src/popup.html`, `src/popup.css`, `src/popup.js`: 操作画面
- `images/`: アイコンと画像
